# Spoty 🎧

[![Android CI](https://github.com/zigorminsk-debug/spoty/actions/workflows/android.yml/badge.svg)](https://github.com/zigorminsk-debug/spoty/actions/workflows/android.yml)
[![Latest release](https://img.shields.io/github/v/release/zigorminsk-debug/spoty?label=APK)](https://github.com/zigorminsk-debug/spoty/releases/latest)

Музыкальное приложение для Android в духе Яндекс Музыки и Spotify: находит альбомы и исполнителей
в **свободных источниках**, каталогизирует их на устройстве и воспроизводит музыку — в том числе в фоне.

> Spoty не хранит музыку на своих серверах: приложение ищет и воспроизводит записи, опубликованные
> в открытых источниках их правообладателями.

## Возможности

**Источники (бесплатно, без аккаунтов)**
- **Audius** — открытая стриминговая сеть, миллионы треков;
- **Internet Archive** — нетлейблы, концертные записи, винтаж (76 000+ альбомов);
- **Jamendo** — музыка Creative Commons (нужен бесплатный `client_id` с devportal.jamendo.com — вводится в настройках).

**Лучшее из Я.Музыки**
- 🌊 **Моя волна** — бесконечный персональный поток: учится на лайках, дизлайках и истории, очередь пополняется сама;
- волна по настроению (бодрое, фокус, сон, вечеринка…), по жанру и по треку/исполнителю;
- уведомления о новых релизах исполнителей, на которых вы подписаны.

**Лучшее из Spotify**
- главный экран с подборками «Для вас», трендами, популярными альбомами и исполнителями;
- единый поиск по всем источникам сразу (треки/альбомы/исполнители);
- коллекция: лайки, подписки, сохранённые альбомы, плейлисты с ручной сортировкой;
- полноэкранный плеер: перемотка, перемешивание, повтор, очередь, скорость, таймер сна, системный эквалайзер;
- 📜 **тексты песен** с синхронизацией по времени (LRCLIB) и перемоткой по строке.

**Своё**
- 📚 **Каталог**: всё найденное сохраняется в локальную базу (Room) — просмотр, фильтры по источнику, сортировка и офлайн-доступ;
- ⬇️ загрузка треков для офлайн-прослушивания (WorkManager, докачка, только Wi-Fi по желанию);
- дисковый кэш стриминга — повторные прослушивания не тратят трафик;
- экспорт/импорт медиатеки в JSON;
- русский и английский интерфейс, тёмная/светлая/динамическая тема.

**Фоновая работа**
- воспроизведение в `MediaLibraryService` (Media3/ExoPlayer): работает при выключенном экране и закрытом приложении;
- уведомление с управлением, экран блокировки, Bluetooth-гарнитуры, **Android Auto**;
- очередь и позиция восстанавливаются после перезапуска.

## Установка

Готовый APK — в [Releases](https://github.com/zigorminsk-debug/spoty/releases):
- `v1.0.N` — сборки из `main` (стабильные);
- `dev-<ветка>` — свежие сборки из рабочих веток.

Требуется Android 8.0+ (API 26). Рядом с APK лежит файл `.sha256` для проверки целостности.

## CI: автосборка после любых изменений

Workflow [.github/workflows/android.yml](.github/workflows/android.yml) запускается на **каждый пуш в любую ветку**:

1. собирает release-APK и прогоняет unit-тесты;
2. подписывает APK **постоянным ключом** и сверяет отпечаток сертификата с эталоном
   (`signing/CERT_SHA256`) — сборка падает, если ключ вдруг изменился;
3. выкладывает APK как артефакт и публикует релиз (из `main` — обычный, из веток — pre-release `dev-*`);
4. при ошибке компиляции публикует выжимку из лога прямо в аннотации запуска.

## Подпись

Все сборки подписаны одним ключом (RSA-4096, действует до 2056 года), поэтому каждая новая версия
ставится **поверх предыдущей** без удаления и потери данных. Отпечаток сертификата:

```
E8:DE:F5:B2:01:9C:E0:52:5B:93:DF:08:71:B9:0A:87:8E:13:41:65:AF:BC:36:F5:FB:6C:52:7A:78:2E:7F:F2
```

Подробности и инструкция по переходу на ключ из GitHub Secrets — в [signing/README.md](signing/README.md).

## Сборка локально

```bash
./gradlew assembleRelease   # нужен JDK 17 и Android SDK (compileSdk 36)
```

## Технологии

Kotlin · Jetpack Compose (Material 3) · Media3/ExoPlayer · Room · WorkManager · DataStore ·
OkHttp · kotlinx.serialization · Coil · Navigation Compose. Без Google-сервисов и аналитики.
