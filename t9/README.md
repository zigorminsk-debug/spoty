# Spoty T9 — T9-ввод для Windows (RU + EN)

T9-вводной метод для Windows, написан на **Go** (без внешних зависимостей,
один exe со словарём внутри). Поддерживает **русский** и **английский**
языки (автоопределение по языку набираемого слова или закрепление языка),
а после первого запуска **загружается вместе с системой**.

## Как пользоваться

1. Запустите `spoty-t9.exe` один раз — программа скопирует себя в
   `%LOCALAPPDATA%\SpotyT9`, пропишет автозапуск и появится в
   **области уведомлений** (значок: зелёный круг = T9 вкл, серый = выкл).
2. Нажмите **F9** (или пункт меню в трейке), чтобы включить/выключить T9.
3. Когда T9 включён, набирайте **первые буквы слова**, а затем пробел:

   | Набрано | Получится |
   |---------|-----------|
   | `првт` + пробел | `привет` |
   | `вчр` + пробел | `вчера` |
   | `здравствуйт` + пробел | `здравствуйте` |
   | `wrk` + пробел | `work` |
   | `wndw` + пробел | `window` |

   Целые слова (`привет`, `work`) не меняются — T9 «срабатывает» только
   на сокращения. Регистр сохраняется: `Првт` → `Привет`, `ПРВТ` → `ПРИВЕТ`.
4. Backspace стирает символ как обычно; если задуматься надолго
   (пауза > 1 с), слово завершится само.

> ⚠️ При включённом T9 набирайте сокращения только там, где вы реально
> набираете текст. В диалогах/кнопках выключайте T9 (F9) — замена
> происходит по пробелу.

## Автозапуск с системой

При первом запуске (или вручную: `spoty-t9.exe --install`) программа
прописывает в реестре:

```
HKCU\Software\Microsoft\Windows\CurrentVersion\Run
  SpotyT9 = "%LOCALAPPDATA%\SpotyT9\spoty-t9.exe"
```

Поэтому при каждом входе в Windows процесс стартует сам (в трее).
Отключить: меню значка → «Запускать вместе с Windows», либо

```
spoty-t9.exe --uninstall
```

## Настройки

Файл `%APPDATA%\SpotyT9\config.json` (создаётся при первом запуске):

```json
{
  "hotKey": "F9",
  "language": "auto",
  "gapMs": 1000,
  "minLen": 2
}
```

| Поле | Описание |
|------|----------|
| `hotKey` | Глобальная клавиша вкл/выкл: `F9`, `Ctrl+Alt+T`, `Shift+F12`, … |
| `language` | `auto` (по языку слов), `ru`, `en` |
| `gapMs` | Пауза тишины (мс), после которой слово завершается само |
| `minLen` | Минимальная длина набираемого слова, чтобы T9 сработал |

Язык и автозапуск меняются и без перезапуска — из меню значка в трее.
Горячую клавишу и `gapMs`/`minLen` меняют из файла (затем перезапуск).

Журнал: `%LOCALAPPDATA%\SpotyT9\spoty-t9.log` (пункт меню «Открыть журнал»).

## Сборка

Требуется Go ≥ 1.22. На Windows:

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

Кросс-сборка (Linux/macOS):

```sh
make            # dist/spoty-t9-windows-amd64.exe
make test       # тесты движка (чистый Go, работают на любой ОС)
```

Флаги: `-ldflags "-s -w -H windowsgui"` убирают консольное окно и
символьную таблицу. В CI (`.github/workflows/t9.yml`) сборка
`spoty-t9.exe` поднимается артефактом на каждый push.

## Как устроено

- **Глобальный low-level хук клавиатуры** (`WH_KEYBOARD_LL`) накапливает
  «черновик» набираемого слова (только буквы; Ctrl/Alt/цифры сбрасывают).
- По пробелу/Enter/знаку препинания движок подбирает слово из словаря:
  набранные буквы должны встречаться **по порядку с первой буквы**;
  кандидаты ранжируются по (1) числу пропущенных букв,
  (2) раннему «закрытию» слова, (3) частотности.
- Замена выполняется через `SendInput`: backspace'ы под длину черновика,
  затем слово (VK-коды через `VkKeyScanW` — корректно в любой раскладке)
  и, если было поглатчено, повторный разделитель.
- Словари: по 20 000 самых частотных слов (RU/EN) из
  [hermitdave/FrequencyWords](https://github.com/hermitdave/FrequencyWords)
  (MIT), вшиты в бинарник через `go:embed`.
- Tray-иконка и меню — чистый `user32` (`Shell_NotifyIconW`), без cgo
  и без внешних Go-пакетов: проект собирается кросс-компиляцией.

## Удаление

1. `spoty-t9.exe --uninstall` (или пункт меню с галочкой автозапуска);
2. закройте программу из трея;
3. при желании удалите `%LOCALAPPDATA%\SpotyT9` и `%APPDATA%\SpotyT9`.
