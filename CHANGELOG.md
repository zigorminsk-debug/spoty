# История версий Spoty

Все сборки подписаны **одним и тем же ключом** (SHA-256 сертификата — [`signing/CERT_SHA256`](signing/CERT_SHA256)),
поэтому новую версию можно ставить поверх старой без удаления данных.

Как читать номера:

- `1.0.N` — `N` это номер запуска GitHub Actions. Счётчик общий для всех веток и событий,
  поэтому в релизах номера идут с пропусками: сборки из рабочих веток и пропущенные
  PR-запуски тоже занимают номер;
- `v1.0.N` — стабильный релиз, собирается из `main` (тег ставится на тот же коммит);
- `dev-<ветка>` — pre-release из рабочей ветки, тег «плавающий»: каждая новая сборка
  из этой ветки перезаписывает его;
- `versionCode` растёт со временем коммита, так что более новая сборка всегда
  устанавливается поверх более старой.

## 1.0.5 — 12 октября 2026

Стабильный релиз [`v1.0.5`](../../releases/tag/v1.0.5), коммит `c296cec` — первый стабильный релиз из `main`.

- В `main` влит PR #1 (`arena/9fbbe404-spoty`) — приложение целиком:
  - источники **Audius**, **Internet Archive**, **Jamendo** (свободные источники, без аккаунтов);
  - каталог на Room, офлайн-загрузки (WorkManager, докачка, только Wi-Fi), дисковый кэш стриминга;
  - «Моя волна» (лайки/дизлайки/история), настроения и жанры, уведомления о новых релизах подписок;
  - полноэкранный плеер: очередь, перемешивание, повтор, скорость, таймер сна, системный эквалайзер;
  - тексты песен с синхронизацией по времени (LRCLIB) и перемоткой по строке;
  - фоновое воспроизведение на Media3 (`MediaLibraryService`), уведомление, экран блокировки, Android Auto;
  - русский и английский интерфейс, тёмная/светлая/динамическая тема, экспорт/импорт медиатеки в JSON;
- CI (`Android CI`): сборка release-APK, unit-тесты, проверка подписи по `signing/CERT_SHA256`,
  публикация релиза с APK и файлом `.sha256`.
